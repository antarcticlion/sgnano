- `skyward_pulse.vgz` — YM2151 + C352 VGM (the load song of the sgnano CPU benchmark `cpubench`). Backing track only.
- `skyward_pulse.mp3` — a recording of the VGZ (44.1 kHz, 320 kbps).

## Third-party material in the VGZ

The drum sounds in `skyward_pulse.vgz` (and so in the MP3) are samples from the **MuseScore_General** SoundFont
(MIT licence; some samples CC0 / public domain). Its full notice is in [`SOUNDFONT_LICENSE.txt`](SOUNDFONT_LICENSE.txt);
keep that file with the VGZ when you redistribute it.

## What is distributed

Only the VGZ and the MP3 (with this file and `SOUNDFONT_LICENSE.txt`). The MIDI file and the chord chart in this
folder are working files and are not part of the public distribution.
