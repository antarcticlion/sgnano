# ファイラーの表示の言語の文字列（resources/locale）

ファイラーの画面の文字列の訳。実機ではシステムのドライブの `S:/SystemFiles/Locale/<code>.txt` に置き、ファイラーの Alt+F8（設定）で選ぶ。
仕組みは `src/filer/fstr.c`、形は `template.txt`（`scripts/make_locale.py` が作る）、確かめは `python3 scripts/make_locale.py --strict`。

## ファイル

- `<code>.txt`: 言語ごとの文字列（UTF-8、タブ区切り。`ui` は日本語 -> 訳、`msg.*` は英語の知らせ -> 訳）
- `template.txt`: 訳すべき文の一覧（自動で作る。手で直さない）
- `src/build_ids.py`（2026-11-16）: 番号つきの訳 `src/work/<code>.tsv`（`U001`〜 画面の文、`M001`〜 知らせ、`N001`〜 2026-11-16 に足した文）から `<code>.txt` を作る。番号は `src/work/strings.tsv`（英語）と `src/work/keys.json`（日本語の鍵・知らせの並び）。% の並び・ファンクションキーの幅（8 桁、英語が長ければその幅まで）を確かめる
- `src/fill_existing.py`（2026-11-16）: 既存の `<code>.txt` を今の鍵にそろえる（ある訳は残し、`src/work/<code>_fill.tsv` で補い、古い鍵を外す）。`src/add_extra.py` は `N` の文を既存のファイルへ足す
- `src/`: 訳を作った台本。`lang_<code>.py` に英語を鍵にした訳を書き、`python3 resources/locale/src/gen2.py <code>` で `<code>.txt` を作る
  （`ui_tr.py` は日本語 -> 英語・韓国語、`msg_ko.py` は知らせの英語の並びと韓国語、`gen.py` は en / ko を作った最初の台本）
